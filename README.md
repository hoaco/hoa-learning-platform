
# Hang Out Academy — Learning Platform

An interactive English learning platform designed to help students learn, practise and connect.

## Project overview

HOA Learning Platform is a subscription-based English learning platform aligned with the Common European Framework of Reference for Languages (CEFR).

## Current development stage

**Prototype v1.0**

The current prototype demonstrates:
- Student dashboard and social activity feed.
- Interactive learning path and course overview.
- Progressive unit unlocking.
- Four language skills: Listening, Speaking, Reading and Writing.
- Resource Library.
- Friends and progress tracking.
- Basic, Premium and Premium+ plans.
- Demo login and personalized progress.

## Technology roadmap

- Frontend: HTML, CSS and JavaScript.
- Hosting: Netlify.
- Backend and database: Supabase.
- Version control: GitHub.
